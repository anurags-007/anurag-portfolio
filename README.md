# Anurag Kumar Singh - Portfolio

Welcome to my personal portfolio website! This project showcases my skills, projects, and certifications in the field of Cybersecurity and Full-Stack Development.

## 🚀 Live Demo
[View Portfolio](https://anurags-007.github.io/anurag-portfolio/)

## 🌟 Features
- **Futuristic Design**: Cyber-themed UI with an "Arc Reactor" profile display and system boot animation.
- **Interactive Elements**: Particle background effects, pulse animations, and a custom lightbox for the gallery.
- **Theme Toggle**: Switch between Light and Dark modes.
- **Visitor HUD**: Real-time display of visitor's system info (OS, IP, Location) using PyScript.
- **Responsive Layout**: Optimized for all devices.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **Python Integration**: PyScript (for visitor intelligence features)
- **Libraries**: Particles.js, Google Fonts (Orbitron, Rajdhani, Marvel)

## 📂 Sections
- **About**: Brief introduction and professional goals.
- **Skills**: Categorized view of programming languages, cybersecurity tools, and other skills.
- **Projects**: Highlights of key projects like IAM Implementation and this Portfolio.
- **Certifications**: Gallery of certificates from TCS, Cisco, Python Institute, etc.
- **Contact**: Social links to GitHub, LinkedIn, YouTube, and Email.

## ⚙️ Setup
To run this project locally:
1. Clone the repository:
   ```bash
   git clone https://github.com/anurags-007/anurag-portfolio.git
   ```
2. Open `index.html` in your browser.
